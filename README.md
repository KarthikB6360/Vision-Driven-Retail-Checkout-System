# Vision-Driven Automated Purchasing Platform with Nutrition Intelligence and Behavioral Analytics

## 📌 Project Overview
The **Vision-Driven Automated Purchasing Platform** is an AI-powered smart retail checkout system designed to automate shopping and billing processes using Computer Vision, Artificial Intelligence, and Behavioral Analytics.

The platform automatically detects products using AI-powered vision models, generates smart billing, provides nutrition analysis, and improves customer shopping experience through intelligent automation.

This system reduces manual billing delays, minimizes human errors, improves shopping efficiency, and creates a modern smart retail environment.

# ⚙️ Complete Installation & Setup Guide

## 1️⃣ Clone Repository

```bash
git clone https://github.com/KarthikB6360/Vision-Driven-Retail-Checkout-System.git
```

---

## 2️⃣ Navigate to Project Folder

```bash
cd Vision-Driven-Retail-Checkout-System
```

---

# 🐍 Backend Setup

## 3️⃣ Create Python Virtual Environment

```bash
python -m venv .venv
```

---

## 4️⃣ Activate Virtual Environment

### Windows

```bash
.venv\Scripts\activate
```

### Linux / Mac

```bash
source .venv/bin/activate
```

---

## 5️⃣ Install Python Dependencies

```bash
pip install -r requirements.txt
```

---

## 6️⃣ Run Backend Server

```bash
python app.py
```

---

# 📱 Frontend Setup

## 7️⃣ Install Node Modules

```bash
npm install
```

---

## 8️⃣ Run Frontend Application

```bash
npm start
```

or

```bash
expo start
```
